  <h1 style="color: #2c3e50;">📘 Attendance System</h1>

  <h2 style="color: #34495e;">👤 User Panel</h2>
  <p>The user interface includes the following features:</p>
  <ul>
    <li><b>Registration and Login</b> pages.</li>
    <li><b>Three main buttons:</b>
      <ul>
        <li><b>Mark Attendance</b> – allows students to mark themselves as present.</li>
        <li><b>Mark Leave</b> – allows students to request a leave.</li>
        <li><b>View Attendance</b> – displays all attendance records for the student.</li>
      </ul>
    </li>
    <li>Students can <b>only mark attendance once per day</b> and <b>cannot delete it</b>.</li>
    <li>Option to <b>edit profile picture</b>.</li>
    <li>Users can <b>send leave requests</b> to the admin for approval.</li>
  </ul>

  <h2 style="color: #34495e;">🛠️ Admin Panel</h2>
  <p>The admin dashboard provides full control over the attendance system:</p>
  <ul>
    <li>Secure <b>login for admin</b>.</li>
    <li><b>View all student login records</b>.</li>
    <li><b>Manage attendance</b>:
      <ul>
        <li>Edit student attendance.</li>
        <li>Add new attendance entries.</li>
        <li>Delete incorrect or invalid entries.</li>
      </ul>
    </li>
    <li><b>User Report Generation</b>:
      <ul>
        <li>Filter by specific user.</li>
        <li>Use <b>FROM and TO date range</b> to generate detailed attendance reports.</li>
      </ul>
    </li>
    <li><b>Leave Management</b>:
      <ul>
        <li>Approve or reject leave requests.</li>
        <li>View total <b>Leaves, Presents, Absents</b> per user.</li>
      </ul>
    </li>
    <li><b>System Report</b>:
      <ul>
        <li>Generate attendance reports for <b>all users</b> using FROM and TO date range.</li>
      </ul>
    </li>
    <li><b>Grading System Module</b>:
      <ul>
        <li>Admins can define grading rules:</li>
        <li>Example: 26 Days = A grade, 10 Days = D grade, etc.</li>
      </ul>
    </li>
  </ul>

  <hr>

  <p style="font-size: 14px;">This system is designed to provide a robust, easy-to-use solution for managing student attendance and leave workflows.</p>
